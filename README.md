# Manual Installation
 
# Clone the repository
```bash
git clone https://github.com/yourusername/openhacker.git
cd openhacker
```
# Install dependencies
```bash
pip install -r requirements.txt
```

# Run requirements check
```bash
python3 requirements-check.py
```

# Start openHacker
```bash
python3 openhacker.py
```
